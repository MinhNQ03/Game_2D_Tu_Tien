## How to add an entry (do this BEFORE importing the asset)

Record all of:
- **Name** — the file/asset name as used in the repo.
- **Type** — sprite / tileset / UI / music / sfx / font / shader / other.
- **Source / Author** — who made it.
- **URL** — where it came from.
- **License** — exact license (e.g. CC0, CC-BY 4.0, OGA-BY, MIT, purchased-with-license).
  For CC-BY and similar, note the required attribution text.
- **Used in** — where in the game it appears.
- **Attribution required?** — Yes/No; if Yes, the exact attribution string.

## License quick-guidance

- **CC0 / public domain** — no attribution required (still record provenance here).
- **CC-BY / OGA-BY / similar** — attribution required; keep the exact credit string and
  surface it in the in-game credits.
- **Purchased / asset-store** — keep the license/receipt reference and confirm it allows
  distribution in a shipped game.
- **Unknown / unclear** — **do not use.** Find a properly licensed alternative.

## Fonts (special attention)

The game font must cover full Vietnamese diacritics + English and have a license that
permits embedding/distribution. Record it here when chosen (none chosen yet).

## Release checklist (assets)

- [ ] Every entry above has a clear, compatible license.

- [ ] Placeholder stock assets (e.g. default `icon.svg`) replaced or cleared for use.
- [ ] Chosen font's license permits distribution and covers Vietnamese glyphs.
